## ¿Qué es AgroManager Pro?

**AgroManager Pro** es una aplicación web diseñada para ayudar a agricultores, dueños de fincas y administradores del campo a llevar el control total de su operación desde cualquier dispositivo con internet.

Esta versión utiliza **Oracle Cloud** como motor de base de datos, una de las plataformas de almacenamiento de datos más seguras y robustas del mundo, utilizada por grandes empresas y gobiernos a nivel global. Esto significa que tu información está siempre disponible, respaldada y protegida en la nube.

Olvídate de los cuadernos, las hojas de cálculo desordenadas o los apuntes en papel. Con AgroManager Pro tenés todo centralizado en un solo lugar.

---

## ¿Qué podés hacer con AgroManager Pro?

### 🌾 Gestión de Parcelas
Registrá cada lote o parcela de tu campo: superficie, cultivo actual, estado de la tierra e inversión realizada. Visualizá todo de un vistazo en un panel claro y ordenado.

### 👷 Control de Trabajadores
Gestioná roles, salarios y horas trabajadas de cada empleado. Llevá el registro completo de tu equipo sin complicaciones.

### 🚜 Seguimiento de Maquinaria
Controlá el estado de tus tractores, cosechadoras y equipos. Sabé cuándo fue el último mantenimiento y cuál está disponible para trabajar hoy.

### 🌱 Campañas de Cultivo
Creá y seguí cada campaña de siembra o cosecha desde el inicio hasta el cierre. Cada campaña incluye:
- **Diario de cosecha** — Registrá avance diario: hectáreas cortadas, bultos y notas del día
- **Remisiones** — Generá documentos de despacho con datos del conductor, vehículo, origen, destino y valor del flete

### 💧 Planificación de Riego
Organizá los turnos de riego y llevá un historial para optimizar el uso del agua en tu campo.

### 🐛 Control de Plagas
Registrá incidentes de plagas con el tipo, cultivo afectado, severidad y tratamiento aplicado para actuar a tiempo.

### 🌿 Inventario de Semillas y Fertilizantes
Controlá existencias de semillas y registrá aplicaciones de fertilizantes por parcela para nunca quedarte corto.

### 💰 Finanzas del Campo
Registrá ingresos y egresos de tu operación con categorías claras. Tené siempre un panorama real del estado financiero de tu finca.

### 📄 Reportes en PDF
Exportá resúmenes y reportes de tu operación en formato PDF para presentar, archivar o compartir con socios e inversores.

### 🤖 AgroBot — Tu Asistente con IA
Un chatbot integrado que responde tus preguntas sobre plagas, riego, fertilización, maquinaria, campañas y finanzas. Como tener un asesor agrícola disponible las 24 horas.

## ¿Por qué Oracle Cloud?

A diferencia de una base de datos instalada en una computadora local, **Oracle Autonomous Database** guarda tu información de forma segura en servidores en la nube, con respaldo automático y disponibilidad desde cualquier lugar. Es la misma tecnología que usan bancos, aerolíneas y empresas Fortune 500.

| Característica | Beneficio para vos |
|---|---|
| ☁️ Almacenamiento en la nube | Tus datos no se pierden si se rompe una computadora |
| 🔒 Encriptación y seguridad | Datos protegidos con estándares empresariales |
| 🌍 Acceso desde cualquier lugar | Consultá tu campo desde el celular, la oficina o el campo |
| 🔄 Respaldo automático | Sin necesidad de hacer copias de seguridad manualmente |

## Estructura del proyecto

```
AgroManager_Oracle/
├── 📁 Backend/          → Servidor y API
│   ├── src/
│   │   ├── routes/      → Endpoints de la API (incluye dashboard y fertilizantes con stock)
│   │   ├── controllers/ → Lógica de cada módulo
│   │   ├── services/    → Reglas de negocio e IA
│   │   └── config/      → Configuración y conexión Oracle
│   └── db/
│       └── schema.sql   → DDL completo: tablas, triggers, tipos PL/SQL, vistas y procedimiento
│
├── 📁 Frontend/         → Interfaz de usuario
│   └── src/
│       ├── views/       → Páginas principales
```
